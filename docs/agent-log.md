# Agent Log — shared cross-agent memory

Append-only coordination log between Milo's specialist agents (curriculum, frontend, backend, devops, security, qa, product-lead). This is the **shared memory** — the one place a role records something another role needs to know. `handoff.md` stays the human-facing session summary; this stays terse and machine-oriented.

## Protocol
- **Read the last ~20 lines at the start of your task** to catch decisions/handoffs from other roles.
- **Append one line when you finish something another role depends on** — a data-shape change, a locked decision, an open question, a "X now needs to do Y". Don't log routine work.
- Format: `- YYYY-MM-DD · <role> · <fact / handoff / open question>`
- Newest at the bottom. Never rewrite history — correct with a new line.
- **`LESSON:` entries.** When a defect is CONFIRMED (not suspected), append
  `- YYYY-MM-DD · LESSON · <responsible role> · <defect class> → <the gate that now catches it, or "no gate">`.
  This is how a one-off mistake becomes something the org stops repeating: the line here is the
  breadcrumb, `docs/lessons.md` is the durable write-up, and the responsible role's
  `.claude/agents/*.md` gets the reasoning habit if it's a habit rather than a rule.
  Order of preference every time: **an executable gate > a type/API shape > an agent
  definition > prose**. A lesson worth logging is usually worth a test.
