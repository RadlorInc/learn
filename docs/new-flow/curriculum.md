# New flow — the topic split for Grades 3–8

Every module is split into single-skill topics, one idea each, picture before number, each topic built on
the one before. Module titles follow the school curriculum PDFs (`grade-1-5-curriculum.pdf`,
`grade-6-12-curriculum.pdf`); Grade 6–8 "modules" are that PDF's topic bands, in its order.

- **Grade 3 Modules 1–6** — founder-approved 2026-09-13 (also in README.md).
- **Grades 4–8** — written 2026-09-14. ⚠️ The founder chose to build these **without reviewing the split or
  the scripts first** ("no review, build all"). Nothing below Grade 3 has been read by the founder.
- **Grade 8** is the regular track (founder's call); Algebra I (accelerated) is not built.

Lesson ids are `g<grade>m<module>-t<topic>`. Content lives in `src/features/lessons/content/g<grade>m<module>.ts`.
